## [1.0] – 2020-12-01

### Added

- Omega Chess game with 10×10 board and corner squares.
- Champion and Wizard piece types.
- Multi-threaded game server with socket-based protocol.
- Desktop client built with libGDX.
- User registration, login, and profile management.
- Game invitations and matchmaking.
- Legal move validation, checkmate detection, and forfeit handling.
- Game records and notification system.
- Unit tests for all chess pieces, board logic, and server components.
